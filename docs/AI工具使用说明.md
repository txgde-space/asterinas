# AI 工具使用说明

## 一、总体说明

本项目在星绽操作系统（Asterinas）网络栈功能扩展过程中，按比赛允许范围使用了 ChatGPT、Codex 等 AI 工具。AI 参与了源码阅读、方案分析、功能代码实现和测试工具开发，其中大部分功能代码由 AI 辅助编写。项目最终采用的技术方案、代码修改和测试结果，均由参赛队伍人工审核并通过实际运行验证。

### 使用流程

1. **源码与架构学习**  
   借助 AI 阅读 Asterinas 源码，梳理 Framekernel 架构、网络栈结构及底层 smoltcp 的相关能力。

2. **需求与缺失能力分析**  
   由团队从真实网络服务运行所需的基本能力出发，结合比赛技术指标，分析 Asterinas 与 Linux 常用网络语义之间的差异，确定需要补充或完善的功能。

3. **技术方案设计**  
   使用 AI 辅助学习相关实现方法、数据结构和处理流程；团队再结合 smoltcp 的现有能力、Asterinas 的架构边界和实际运行需求，自主确定具体实现方案。

4. **代码实现与迭代**  
   大部分功能代码由 AI 根据团队确定的技术思路辅助编写，AI 同时参与错误分析和后续修改。所有代码均由团队结合源码上下文进行人工审核，通过编译和运行验证后提交。后续发现问题时，再根据日志和测试结果反复修改、验证并形成新的 Git 提交。

5. **测试与展示工具开发**  
   测试目标和测试思路由团队确定，包括与 Ubuntu 的兼容性对比、真实 Flask 网络服务运行测试，以及三个技术指标的快速复现和可视化交互测试。AI 主要协助完成可视化前端和部分测试后端代码；Asterinas 的编译、启动、内核运行和网络配置命令均由团队人工执行和确认。

> **使用原则：** AI 深度参与了代码实现和测试工具开发，但 AI 输出不直接作为最终技术结论或测试依据。项目中的技术路线、代码修改、测试方法、运行结果和提交内容均由参赛队伍人工审核并负责确认。

## 二、各技术指标中的使用情况

### 1. Raw Socket 支持与 Ping 可用性

- **前期基础：** 参赛队伍已具备 Raw Socket、TCP Socket 和 UDP Socket 的基础知识。
- **AI 辅助：** 分析 Asterinas 和 smoltcp 的网络栈源码，确认 Asterinas 当时缺少面向用户态的 IPv4 Raw Socket 支持，并辅助梳理接口与数据包处理流程。
- **团队决策：** 确定在用户态提供 Raw Socket 接口，使应用能够绕过 TCP、UDP 传输层处理，直接收发指定 IP 协议的数据包，并完成 ICMP Echo 请求与响应链路。
- **实现与验证：** 相关功能代码主要由 AI 根据既定方案辅助编写，并协助进行问题定位和迭代修改；团队负责源码审核、编译检查和运行测试，并根据日志与实际数据包处理结果确认修改是否有效。Raw Socket 创建、数据收发、Ping 流程和异常处理符合预期后，再提交代码。

### 2. Socket 功能扩展与 Linux 兼容性增强

- **AI 辅助：** 分析 Asterinas 与 smoltcp 对 IP 地址、网络接口和 Socket 绑定关系的处理方式，帮助团队理解多网卡环境下 `INADDR_ANY` 等 Linux Socket 语义无法完整实现的原因。
- **团队决策：** 考虑到 smoltcp 是上游网络协议栈依赖，决定不直接修改其源码，而是在 Asterinas 网络栈内部补充多接口管理和 Linux 兼容语义。
- **实现与验证：** 相关功能代码主要由 AI 辅助实现，并由 AI 协助梳理调用关系、分析问题和迭代修改；团队通过 Ubuntu 兼容性对比、多网卡 Socket 和真实 Flask 服务运行等测试，检查端口绑定、连接恢复、资源释放及多接口行为。所有修改经人工审核和重复测试后，再形成 Git 提交。

### 3. Netfilter、连接跟踪与 NAT 功能实现

- **AI 辅助：** 学习和梳理 Linux Netfilter 的基本设计，包括五个 Hook 点、Table—Chain—Rule 组织方式、iptables 控制语义、连接跟踪，以及 DNAT、MASQUERADE 的处理流程；同时用于检索相关技术资料、解释部分网络协议行为和辅助分析测试日志。
- **团队决策：** 将 Linux Netfilter 的设计作为参考，结合 Asterinas 与 smoltcp 的实际架构，确定技术路线和实现方案取舍，并未直接照搬 Linux 的具体实现。
- **实现与验证：** Netfilter、连接跟踪和 NAT 相关功能代码主要由 AI 根据团队确定的方案辅助实现，并协助分析测试日志和修改问题；团队负责审核代码、执行真实网络环境测试并确认功能表现。相关修改以实际测试结果为依据，确认无误后再形成 Git 提交。
